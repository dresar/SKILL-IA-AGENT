# UI/UX Text

> Standar microcopy ultra-minimalis dengan batas maksimal 1 kalimat.

## Kategori
Design Systems

## Instalasi
```bash
npx skills add dresar/SKILL-IA-AGENT -s ui-ux-text
```

## Demo Prompt
```text
Refactor verbose modal buttons and descriptions into ultra-minimalist microcopy.
```

## Demo Output
```typescript
<Button variant="primary">Simpan</Button>
<p className="text-xs text-text-muted">Perubahan disimpan secara otomatis.</p>
```
