# Taste Filter

> Filter estetika tingkat lanjut untuk memblokir pola AI template generik.

## Kategori
Design Systems

## Instalasi
```bash
npx skills add dresar/SKILL-IA-AGENT -s taste-filter
```

## Demo Prompt
```text
Detect and replace generic bootstrap gradient cards with bespoke styling.
```

## Demo Output
```typescript
// Banned: generic rounded-lg border shadow-md gradient-to-r
// Replaced with: bespoke hairline bezel + OLED surface
```
